# 终端机外观与层叠结构 V0.1

状态：Accepted visual direction（2026-08-30）  
范围：纯视觉语言、外壳分层、开发板散热组件和一体蜂窝后盖风道的工程占位。本文不是最终 CAD、BOM、IP 等级或热设计结论；尺寸、风扇、材料厚度、风向和电池位置继续以实物 `MEASURED` 数据冻结。  
正式产品名：**A.I.Live-ai枪娘器灵**。`SKIPPY`仅为历史代号，不再用于新外观丝印。

## 1. 设计意图

终端机是一台以 3.5 英寸横屏为核心的微缩“战术数据平板”，安装后应像枪身自然长出的附件，而不是开发板、转接线和屏幕的临时拼装。

视觉关键词：

```text
微缩三防平板
+ 相机半笼
+ 圆角装甲
+ 蜂窝散热背板
+ 外露沉头紧固件
+ 少量荧光黄识别线
```

首轮正面外廓继续由样屏实物决定；当前只保留横向长方形、R5–R8 级大圆角、边缘梯形收束和屏幕内缩的比例方向，不把商品图尺寸直接变成最终 CAD。

## 2. 三层核心结构

用户冻结的基本层叠为“屏幕在前、主板在中，散热器/小风扇安装在开发板上，最外层是一体蜂窝后盖”：

```text
用户视线 / 正面
        ↓
┌──────────────────────────────────┐
│ 前部保护层                       │
│ 透明保护片 + 内缩屏幕 + 橡胶隔离 │
│ 哑光黑铝合金半笼 / 四角沉头螺丝  │
├──────────────────────────────────┤
│ 中部电子层                       │
│ 3.5inch LCD / DP→HDMI / 短线     │
│ 可更换主板托盘 / 主板 / 应变释放  │
│ 天线非金属窗口 / 板载散热器与风扇 │
├──────────────────────────────────┤
│ 一体式蜂窝后盖                   │
│ 内侧流线型让位凹槽 / 防护格栅     │
│ 侧向呼吸通道                     │
├──────────────────────────────────┤
│ 四角泡棉 + 刚性止挡 + 中央风道    │
└──────────────────────────────────┘
        ↓
枪身 / 收纳贴合平面
```

三层必须可以分别维护。正面半笼夹持外壳和屏幕支撑区，不能直接夹 LCD 有效区；主板固定在独立托盘上；风扇属于开发板散热组件，拆下后盖后可以维护，但不固定在后盖上，也不要求先拆屏幕或三轴底座。

## 3. 正面视觉

- 屏幕表面相对最外保护边框下沉约 1–2 mm，数值为 `ESTIMATED`，由保护片、触摸和视角实测修正。
- 哑光黑铝合金半笼包住四角与上下边缘，两侧大面积挖空；外露沉头内六角螺丝属于设计语言，同时必须是真实可维护紧固点。
- 半笼与屏幕之间使用薄橡胶隔离片，金属不能直接摩擦玻璃，也不能把外壳扭矩传给 LCD。
- 开孔只在对应真实散热、减重或装配需求时保留；不制作看似风道但背后封死的装饰孔。
- 推荐正面丝印：`A.I.LIVE // GUN SPIRIT`与`PROTOTYPE P0`。不再新增`PROJECT SKIPPY`。

## 4. 背面视觉与蜂窝格栅

- 背面主体采用大面积六边形蜂窝语言。实孔区域服务于风扇防护和气流，非通风区域可使用 0.5–1 mm `ESTIMATED`浅凹纹保持连续视觉。
- 后盖是一体件。内侧按照Zero 3W主板、USB-C DP主动转HDMI件、接头和板载散热组件的包络设置流线型局部让位凹槽，使外壳贴近硬件，而不是做成等厚空盒。
- 让位凹槽不得接触或压住 PCB、元器件、接头、散热器或风扇；必须保留装配公差、绝缘层和气流净空，具体最小值待实物测量。
- 外表面可以把内部让位关系转化为浅而连续的流线型凹面，但不能形成容易积泥、勾挂装备或削弱后盖的尖锐深槽。
- 蜂窝格栅必须阻止手指、线头、泡棉和软包装接触扇叶；具体孔径、筋宽和厚度由风量、噪声和强度测试决定。
- 四角泡棉不是唯一限位。泡棉内侧设置刚性止挡，控制屏幕贴合时的最大压缩量，并保护 LCD、按键、电芯和风扇。
- 四角支撑应在背面中央形成持续空气间隙；侧边同时保留至少一组真实通风口。终端机贴枪或贴墙后，散热不能依赖背面正对外界完全敞开。
- 中央标识使用`SPIRIT CORE`或正式产品标识。装饰警示改为`CAUTION // ELECTRONIC EQUIPMENT`、`5V SYSTEM`或`FIELD PROTOTYPE`，禁止使用与实际低压系统不符的`HIGH VOLTAGE`。

## 5. 开发板散热器/风扇与一体蜂窝后盖

风扇冻结为开发板自身的主动散热件，通过适配支架、螺钉或卡扣安装在 SoC 散热器上，而不是另设一层机箱风扇。一体蜂窝后盖只负责保护、硬件让位和导流，不承担风扇固定或 PCB 限位。以下参数继续开放：

- 风扇直径、厚度、轴承、额定电流、PWM/转速反馈与连接器。
- 背面吸入后侧面排出，或侧面吸入后背面排出的具体方向。
- 主板 SoC 使用何种散热片、风扇支架和导热界面。
- 风扇常开、温控分档或故障后被动降级策略。

风道必须满足：

1. 冷空气先经过主板主要热源，再排出外壳；不得让热风在屏幕、主板和后盖之间短路循环。
2. 后盖蜂窝/侧向开口需对准板载风扇与散热器；收纳贴合、四角泡棉受压、常见握持和三轴全角度时仍有可测气流路径。
3. 风扇停转、蜂窝局部堵塞或积尘时，Host能够降级负载并保持安全关机；不能依赖风扇永不失效。
4. 风扇振动不能通过 LCD 或半笼放大，不应影响触摸、IMU、角色显示和三轴关节手感。
5. 外壳最终是否具有防泼溅能力，必须通过密封与风道共同设计；开蜂窝本身不代表任何 IP 等级。

## 6. 电池与天线占位

电池仍属于移动主机舱，但本轮不把它强塞进屏幕、主板和板载散热组件的主热区：

- 电池不能覆盖板载风扇进风区、散热器排风区或后盖主风道。
- 电池与主板/散热件之间保留隔热、刚性防穿刺和膨胀余量。
- 优先比较下边独立电池仓、侧边条形电池仓或加厚后盖非热区；最终由完整舱质量、重心、温升和 4 h 功耗决定。
- 主板 Wi-Fi/BLE 外置天线放在非金属边缘窗口，远离铝半笼、风扇电机、电池和导轨；三轴全角度实测 RSSI。

## 7. 侧面、按键与接口

- 侧面采用中部略厚、边缘收薄的梯形装甲线条；外壳分缝与检修盖形成真实层次。
- 保留两颗凹入、高阻尼实体键：`POWER`和`MAINT`。亮度由软件或受控组合操作完成，不增加虚假亮度键。
- 橡胶盖下的`USB-C`标识必须对应真实维护/充电接口；不存在接口时使用无文字装甲盖，不能制作欺骗性接口。
- 右下角可保留金属穿绳孔作为二次防丢点，但挂绳不得进入风扇、三轴关节或操作区。

## 8. 配色与材质

| 区域 | 方向 |
|------|------|
| 主体 | 约 70% 哑光深空黑，细砂纹或细喷砂视觉 |
| 辅助 | 约 20% 战术灰，用于背板边缘和半笼内侧 |
| 点缀 | 荧光黄 `#FFE100`，只用于约 1.5 mm 识别线、按键环与小面积标识 |
| 正面半笼 | 哑光黑阳极氧化铝或能达到相同视觉的原型材料 |
| 主壳/背板 | 玻纤增强尼龙、工程塑料或原型打印材料，具体材料待冲击和温升测试 |
| 缓冲 | 黑色微孔聚氨酯或硅胶泡棉，可更换，不使用普通吸水海绵 |

霓虹蓝可作为屏幕内角色/状态光效，不与荧光黄同时在外壳大面积竞争。背面呼吸灯继续作为 P1 可选项，不进入 P0 功耗和故障门。

## 9. 到货后需要冻结的数据

- 屏幕、Zero 3W、主动DP转HDMI件、全部接头和散热件的带线包络、质量与重心。
- 裸板、板载被动散热、板载小风扇三种配置的待机/典型/峰值温度与功耗。
- 一体后盖内侧各让位凹槽相对 PCB、接头、散热器和风扇的最小净空。
- 背面完全敞开、贴枪收纳、遮挡 25%/50% 蜂窝和风扇停转时的温升。
- 四角泡棉高度、压缩曲线、中央风道高度和刚性止挡位置。
- 风扇噪声、振动、PWM可听音、积尘和戴手套误触。
- 铝半笼、外置天线、风扇开/关和三轴角度对 Wi-Fi/BLE RSSI 的影响。
- 完整舱厚度、质量、三轴力矩、贴枪轮廓和玩家对突出感的反馈。

所有结果记录为`DATASHEET | ESTIMATED | MEASURED`，并写明主板/屏幕/风扇料号与测试姿态。没有实测前，本文只冻结视觉与三层位置关系，不冻结散热能力。
