## 7. 已确证的硬事实（引用时以来源文档为准）

**板卡 / 分区**（`HARDWARE_IMPLEMENTATION_PLAN.md` §0.1.1、构建产物）
- ESP32-S3，**16 MB Flash / 8 MB PSRAM**，原生 320×480，MAC `CC:68:C7:84:06:24`
- 分区：`app0`/`app1` 各 **2 MiB**、**`ffat` 11.875 MiB（3,040 扇区全 `0xFF`，空）**、`coredump` 64 KB、`otadata` 8 KB
- 立绘约占 946,400 B；移入 `ffat` 后 `app1` 余量 ≈ **1.44 MiB**（静态估算，以实构建为准）

**引脚**（官方 BSP + 原厂例程交叉核对）
- 背光 **GPIO1**（LEDC 5 kHz/10-bit，**可软件调亮度**）；显示 QSPI CS45/CLK47/D0–3=21/48/40/39（40 MHz）
- 触摸 I²C SDA4/SCL8，地址 **`0x3B`(7 位) = `0x76`(8 位)**——"冲突"是记法差异
- **GPIO17/18 空闲**（P3/P4 同一网络）→ IMU I²C；**S3 ADC1 = GPIO1–10** → FSR 用 GPIO6/7

**供电**（`MAIN_POWER.md` §P0-A）
- P5：**2 脚 = `BAT+`、1 脚 = `BAT−/GND`**（V1.0 图纸；旧记录写反，已更正；**实物丝印仍待核**）
- `U2` 只标位号，**引脚排列与 IP5306H 族相符但未锁料号**；图上无 `ISET/PROG`、**无 NTC**
- 3.3 V 是 **buck**（`U3` + `L3`，从 `VOUT-BAT` 取电）→ **不存在 3.7→5→3.3 的双转换损耗**
- 背光 `LED_A` 接 **3.3 V**，`LED_K` 经 `R13`+`Q2` 到地，GPIO1 PWM
- 电池采样 GPIO5：`R26 33 kΩ` 上臂 / `R27 100 kΩ` 下臂 → 比例 **0.752**；4.2 V → 约 **3.16 V**，**逼近/超出 S3 ADC 有效上限 → 满电段可能读不出，禁止声称百分比**

## 8. 红线（任何会话都不得越过）

1. **不接**载体内部火控、扳机机构、供弹机构；扳机只允许**外部只读耦合**（磁铁 + 霍尔），「读火控信号」已否决。
2. 娱乐后端**只允许**「瞄准射线 × 屏幕平面」求交；**禁止**弹道/初速/下坠/风偏/命中概率/射击解算、辅助瞄准、吸附、命中修正；对外定位娱乐，**不用「训练」**。
3. **U2 未锁定前不接电池**；开发期**只用 USB-C 单路供电，P5 空置**。
4. 电芯**必须自带 PCM**；**只在有人看守时充电**。
5. 不得把计划中的能力写成已验证能力；实测数据不得回填进历史估算。
