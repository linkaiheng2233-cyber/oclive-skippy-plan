### 0.5.2 IMU 最终裁决：改用 ICM-45686（¥73，2026-11-14）

**背景**：所有者实查发现 ¥23 的「GY-601N1 6轴 ICM-42688」实际是 **GY-601N1-bmi323（Bosch BMI323）**，标题挂 ICM-42688 属虚假标注 → 排除该店。真装 GY-601N1（ICM-42688）市价 **¥120–130**。目前最便宜的靠谱候选是 **ICM-45686 模块（¥73）**。

**ICM-45686 事实（多源核实）**：

| 项 | ICM-45686 | ICM-42688-P |
|---|---|---|
| `WHO_AM_I` | **寄存器 `0x72` = `0xE9`** | 寄存器 `0x75` = `0x47` |
| 陀螺噪声 | 3.8 mdps/√Hz | 2.8 mdps/√Hz |
| **加速度噪声** | **70 µg/√Hz** | **70 µg/√Hz（相同）** |
| 量程 | ±4000 °/s、±32 g | ±4000 °/s、±16 g |
| FIFO | 8 KB | 2 KB |
| 电流（6 轴低噪） | 0.42 mA | ~0.88 mA |
| 抗振 | **BalancedGyro** | 无 |
| 发布 | 2024 | 2020 |

**官方驱动可用性**（推翻"没案例"的担心）：[Arduino 官方库](https://docs.arduino.cc/libraries/icm45686/)、[TDK 官方 Arduino 仓库](https://github.com/tdk-invn-oss/motion.arduino.ICM45686)；另有 Zephyr 驱动与 Linux IIO 驱动在推进。

**裁决理由**：
1. **加速度噪声相同** → "举枪/放下/握持"等 P0-A 核心判定无差异；
2. **`0x72/0xE9` 可 5 秒验真假** → 翻新风险可控；
3. **官方驱动齐全** → 集成风险低；
4. 省约 50 元，且 **BalancedGyro 抗振**对电机/波箱震动的发射器是加分；
5. 唯一让步：陀螺噪声略差，对"粗略瞄准"无感。

**采购**：先买 **1 个**（真假靠读 ID 判，两个同款不能互证）；验通后补第 2 个备用。
**若验出假货** → 退回并改买真装 GY-601N1（¥120–130），损失 ¥73 + 一周。

**到货必验**：
1. `0x72` 读 `0xE9`（**这是最短的真假判定**）
2. I²C 地址与 3.3 V 供电确认
3. 原始三轴能读、静止不跳
4. **朝右转 90° 验证角速率符号**（`GS-CONTRACT-005`）
**到货后的验证顺序（每步只加一个变量）**：
1. 先用**万用表 µA 档**串在 nRF52840 供电上，确认板子本身睡眠电流（V7 基线）；
2. 烧最小固件：GPIO 中断唤醒 → 立即发包，用另一台设备/嗅探器测**唤醒到收到**的时间（V6）；
3. 接 ICM-42688-P，静止采样 5 分钟，算零偏与噪声密度（V8）；
4. 磁铁+霍尔做插拔重复性（V9）；
5. 红外+反光贴做拉出/晃动识别（V10）。

**五项全过** → 才进入整机模块套件采购（见 `MODULAR_SENSOR_NETWORK.md` §8，约 230–470 元）。

## 6. 新手避坑速记（对应 00-从这里开始.md 停止条件）

- 台式电源第一次上电：**先设限流**（如 0.5 A）→ 空载测电压 → 再升流；任何异常立即断电。
- XIAO 电池接法：**先测极性**；电池必须带 PCM；USB-C 充电时节点停用、硬开关置于允许电池连接的位置。
- 节点电池到货先存 ~3.8 V，不要满电或空电久置。
- USB-C 线：**认准数据线，不是充电线**（充电线无数据芯，烧录会失败）。
- 成品充电宝：认准固定5V口；持续/峰值能力按Zero 3W台架数据选，旧≥3A不再自动算通过；**不用PD诱骗板**；屏幕不得反向给主板供电。
- MicroSD：到手先备份镜像；**破坏性断电测试只在备份卡上做**。
- FSR/握套：可拆、不粘原枪、不钻孔；任何改变扳机/握持安全的方案直接否决。
- 上枪前必须先后通过桌面闭环和断电机械假体；P0 不接火控、电机、供弹等执行线路。
- **ESP32-S3（P0-A）**：买 **N16R8**（16 MB Flash / 8 MB PSRAM），别买成 4 MB Flash 的版本——素材要空间。**只有 2.4 GHz Wi-Fi**，路由器要有 2.4 GHz SSID。
- **IMU（P0-A）**：**认准 SPI 版本**（很多 ICM-42688-P / QMI8658 模块只引出 I2C）；选 **3.3 V**；确认有 **DRDY/INT** 引脚——采样节拍稳定直接决定陀螺瞄准的手感。
- **扳机霍尔（P0-A）**：**磁铁贴在扳机背面、霍尔固定在护圈外侧**，全程**不开壳、不焊接、不接火控**；撕掉双面胶即可恢复原状。任何往枪内引线或并接原电路的方案**直接否决**。
- **ADC 只能用 ADC1（GPIO32–39）**：ESP32 开 Wi-Fi 时 **ADC2 不可用**——FSR 与将来的线性霍尔都必须落在 ADC1 引脚上。
