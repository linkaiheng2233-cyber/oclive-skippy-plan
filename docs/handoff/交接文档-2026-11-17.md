## 5. 下一步（S1）

**S1：`GameSignal` 类型 + 模拟一局生成器**

- 新建 crate：`ailive-gun-spirit-role-bridge`（**不要**加进 `contracts`）
- 类型：`GameSignal { game_session_id, sequence, emitted_at_ms, provenance=Game, kind }`
- kind（MVP）：`round.started / round.ended / hit.confirmed / miss.recorded / target.destroyed / streak.reached`
- 生成器：模拟打一局，产生完整信号流
- 验收：信号流能被解析、字段校验有测试、`verify.ps1 -SkipAudit` 通过

**约束（务必遵守）**：

1. 游戏事实**不得**转成 `SensorObservation` / `DeviceEvent`
2. 角色内核 → 游戏只允许**表现层**（表情/台词），不得进命中判定与计分
3. 角色层（可含 LLM）**不得阻塞**板端即时表情（≤300 ms）

## 7. 硬件与现场状态

| 项 | 状态 |
|---|---|
| 板卡 | 晶彩 JC3248W535（ESP32-S3，16 MB flash / 8 MB OPI PSRAM）；**右 RESET / 左 BOOT**，烧录需手动进下载模式 |
| 当前固件 | 外部资产 + 内核 + Wi-Fi 版，1,206,xxx B（app1 约 57%） |
| 出厂恢复 | `app0` 永久保留，`./scripts/flash-p0a.ps1 -Factory` 可切回 |
| **IMU** | **已到货：GY-601N1 模块**（同板号可能装 ICM-45686 / ICM-42688 / BMI323，**必须 `IMU PROBE` 判型**）。接口：芯片组 `VCC GND SCL/SCLK SDA/SDI SA0/SDO CS INT1 INT2`，UART 组 `VCC GND RX TX`。接线用 **P3（右上偏左，1.25mm）或 P4（最右上，1.0mm）**，两者同网络：1=GND、2=3.3V、3=GPIO17、4=GPIO18；**P1（Type-C 旁 4 针）不要用** |
| 发射器 | 悍迪 191 为首台载体，选型/采购 20 号后 |
| 传感器件 | 弹匣霍尔、肩托 FSR、前握贴片均未采购 |

## 8. 已知坑与注意

| 现象 | 原因 | 处理 |
|---|---|---|
| `cargo audit` 失败 | 拉不到 RustSec advisory 数据库（网络） | 用 `-SkipAudit`；已记 `GS-DEP-002`，**不是代码回归** |
| 改了中文文案后屏幕出现方框 | 字库是**子集**，新字不在里面 | 跑 `./scripts/font` 生成脚本：`./scripts/build-cjk-font.ps1` |
| 固件构建报缺 LVGL/ESP32 | 工具链未装到脚本预期位置 | 见 `docs/P0A_FIRMWARE_PLATFORM.md` §10 |
| `git clone` 后看不到进度 | 默认分支是 `main` | 必须 `-b docs/personal-document-archive-20261030` |
| 台架 `hello=0` | 契约版本不一致（曾发生三处常量漂移） | 跑 `./scripts/check-contract-parity.ps1` |
| 事件发到串口而不是网络 | 会话未建立 | 已由 `using_socket()` + 15 s 空闲超时兜住 |

**技术债提醒**：`GS-DEP-003` —— 固件里的 `KSYNTH`（合成观测）**必须在 IMU 到货后删除**，否则真实数据与假数据会混在一起。

**公开仓库注意**：本仓库是**公开**的。`sessions/` 里是**脱敏**对话摘录；原始 DSH 会话（含本机路径、Wi-Fi 标识）**不要**提交。
