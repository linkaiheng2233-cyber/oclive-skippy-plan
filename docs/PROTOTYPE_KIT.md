# RADIAN MODEL 1 原型套件路线

## 1. 冻结决定

- 首台原型载体：森柏龙 RADIAN MODEL 1。
- 开发顺序：独立桌面套件 → 套件外壳 → 导轨适配 → 断电上枪检查 → 通电静态测试 → 场地 Alpha。
- v0.1 不接载体内部火控、扳机、供弹或其它机构。
- 传感器默认不走机内线；导轨主模块保留 IMU，远端节点使用表面安装和 BLE，自身完成滤波与低频观察输出。状态判断不依赖磁性放置底座。
- 套件电子核心不为 RADIAN 定制，RADIAN 只作为第一套实物适配与验证载体。
- 开发板尺寸不是主要矛盾；首轮优先保证 Linux 支持、屏幕接口、GPIO/I2C/SPI、Wi-Fi 和稳定供电。
- 显示首选 2.8 英寸、320 × 240 横屏、无触摸、高亮 SPI 裸屏；样屏通过后才冻结三轴屏幕舱，屏幕后方布置主板与 1S 可充电主电池，固定 IMU 留在导轨根部。
- 导轨夹具刚性锁定，屏幕 yaw/pitch/roll 三轴提供摩擦/恒扭矩阻尼，收纳不用磁吸。
- LLM 重推理走云端，物理状态与屏幕即时反馈留在本地。

## 2. 桌面套件最小组成

| 部件 | v0.1 用途 | 首轮形态 |
|------|-----------|----------|
| 小型 ARM64 Linux 开发板 | OCLive Host、状态机、云端网关、屏幕 | 裸板/开发外壳 |
| 小屏 | PNG 表情与极简 HUD | 首选 Newhaven 2.8 英寸 Rev1B 样屏；320 × 240、无触摸、SPI、高亮 |
| 显示背板 | 连接裸屏、调光与保护接口 | 40-pin FFC、4-wire SPI、背光恒流/PWM、复位/TE、ESD 与测试点 |
| 固定 IMU | `picked_up` / `raised`，可试验震动特征 | 导轨根部传感器板，不随屏幕转动 |
| 物理按钮 | 确定性 `triggered` 测试 | 主模块测试键，不接载体内部机构 |
| BLE Central | 接收功能节点 `SensorObservation` | 开发板板载蓝牙或 USB BLE 适配器 |
| Grip Node | 压力判断 `grip.engaged/released` | 带天线 BLE 模块 + 薄膜压力片；先桌面供电，后用可更换 CR2032 |
| USB 电源 | 排除电池变量 | 桌面供电 |
| 主机可充电池 | Linux 主板与屏幕下场供电 | 1S 受保护电池包，屏幕后方；容量先不冻结 |
| Wi-Fi/手机热点 | 云端 LLM | 开发网络 |

首轮不采购扬声器、功放、振动马达、相机、Shoulder Node 和定制主机电芯。Grip Node 先用开发模块与桌面电源验证，无线协议通过后接可更换 CR2032；显示建议采购 1 块官方 breakout + 2 块 Rev1B 裸屏，主机完成样屏和 USB 功耗测试后再选择屏幕后置可充电池。

## 3. 板端与云端分工

```text
板端
  local / BLE sensors → SensorObservation → fusion → DeviceEvent
                                                    │
                                                    ├→ state machine → immediate VisualCue → screen
                                                    │
                                                    └→ OCLive Fast turn → remote LLM endpoint
                                                                             │
                                                                             └→ dynamic visual state
```

板端必须在无网时完成：

- 拿起、举起、触发、放回的状态转换。
- 默认 PNG/HUD 更新。
- 网络状态提示。
- 事件去重、冷却、TTL 和日志。
- 正常退出、重启和 watchdog。

云端不可用时允许失去动态角色文本，但不允许屏幕长时间停在「等待」或设备完全无反馈。

## 4. 套件阶段

### K0：Windows 软件模拟器

键盘产生 DeviceEvent，桌面窗口模拟小屏。验证状态机、VisualCue、OCLive 云端回合和断网降级。

### K1：Linux 裸板点屏

开发板通过 USB 供电；按 `DISPLAY_SELECTION.md` 先用 4-wire SPI 点亮 2.8 英寸候选屏，显示 320 × 240 固定 PNG，再消费 mock VisualCue。记录全帧/局部刷新、首像素延迟、背光 PWM 和两小时稳定性；此时不接传感器、不做外壳。

### K2：传感器桌面闭环

依次接按钮、IMU；驱动层先生成 SensorObservation，融合层再生成与模拟器完全相同的 DeviceEvent。随后接入一个桌面供电的 Grip Node，完成 BLE 配对、重连、断连未知态、两小时 soak 和断网/重启测试。

### K2.5：样屏冻结门

完成正午/树荫/室内、普通/低反射保护片、偏振护目镜、四档背光、功耗与温升测试。只有 320 × 240 UI 和 2.8 英寸样屏同时通过，才制作显示背板与外壳；失败则按 D2 评估 3.5 英寸 640 × 480 MIPI 候选。

### K3：独立套件外壳

为板子、屏幕和接口做桌面/手持保护外壳，并把 Grip Node 改成可更换 CR2032。主机制作屏幕舱堆叠与主电池等质量/等厚度假体，先解决散热、天线净空、压力传递、电池门、检修和固定，不设计 RADIAN 专用外形。

### K3.5：三轴屏幕机构

制作刚性导轨根部 + yaw/pitch/roll 三轴假体。用最轻/标称/最重三种屏幕舱质量选择转轴扭矩，验证收纳机械卡位、泡棉先接触、跨轴线缆弯折和固定 IMU 不受屏幕转动影响。主机电池容量仍由 USB 实测功耗决定。

### K4：RADIAN 安装适配

以实物测量为准，为通用电子核心制作可更换的皮卡汀尼底座。先装断电套件，确认视线、操作、重心和净空；通过后再通电静态测试。

### K5：场地 Alpha

完成误触、漏触、屏幕强光、Grip Node 连接/续航和操控影响记录。只有通过后才评估 Shoulder Node 和更多传感器。

## 5. RADIAN 实物测量清单

不从宣传图推算，使用实物记录：

- 可用导轨槽数量与位置。
- 瞄具视线、上方和侧面净空。
- 主要操作件、握持区和拆装路径的净空。
- 套件允许的最大长、宽、高与目标重量。
- 屏幕 yaw/pitch/roll 三轴的收起/展开视角与限位。
- 约 74–78 × 54–58 mm 屏幕舱正面工程区间在不同导轨位置的包络；最终值以首选样屏完整堆叠为准。
- 主板随屏幕移动与固定两种布局的重心、转轴扭矩和线缆代价。
- 屏幕泡棉贴合点、LCD 内缩量和电池防压空间。
- 主模块内部线缆最短路径、Grip Node 表面固定点和快速拆卸方式。
- 套件安装前后的重心变化。

测量与功耗测试完成前不冻结外壳、铰链扭矩、电芯容量/厚度和导轨夹具。

其它带标准皮卡汀尼导轨的载体复用同一底座；M-LOK、KeyMod 或无导轨载体不改电子核心，另做机械转接件。对外口径是「兼容标准导轨并可扩展转接」，不宣称无需转接即可适配字面意义上的每一把载体。

## 6. 套件上枪前验收门

- Windows 模拟器完成 100 次事件回放。
- Linux 板端无网时仍能完成四个核心事件的屏幕反馈。
- 云端超时/重连不会卡死状态机。
- 实际屏幕连续刷新两小时无花屏、冻结或资源泄漏。
- 正午/树荫/室内与常用偏振护目镜下，核心表情和 HUD 均可辨；事件到首个可见像素 p95 ≤150 ms。
- 三轴任意角度静置不明显下垂，操作时导轨夹具不迁移；1,000 次循环后力矩与线缆正常。
- 屏幕收纳贴合时泡棉/机械止挡承力，LCD 和主电池不承受点载荷。
- 主机电池完成 4 小时完整负载 Alpha；8 小时作为设计目标，并通过边充边用、低电关机和温升测试。
- 按钮和 IMU 不产生事件风暴。
- Grip Node 断连不会把最后一次握持状态永久保留，重连后可恢复当前状态快照。
- 无磁性底座时，握持释放 + IMU 静止能稳定进入待机，握持或运动能恢复。
- CR2032 在低温、电量末期和 BLE 重连峰值下不发生 brownout。
- systemd 自启动与异常重启可恢复。
- 套件可以脱离 RADIAN 独立演示完整闭环。

只有全部满足后，才进入 RADIAN MODEL 1 适配阶段。
