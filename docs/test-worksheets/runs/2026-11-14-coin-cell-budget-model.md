# 纽扣电池续航模型（V5，`ESTIMATED`）

**状态**：`CANDIDATE`（2026-11-14）。**这是模型，不是实测**——V6/V7 才用样品实测校准。
**目的**：在买 nRF52 模块之前，先判断"免充电（纽扣电池）"这条路**理论上是否成立**，避免设计完才发现要几周换一次电池。

---

## 1. 假设与来源

| 项 | 取值 | 证据等级 | 说明 |
|---|---|---|---|
| CR2032 标称容量 | 220 mAh | `DATASHEET` | 常见值 |
| 可用容量（降额） | **200 mAh** | `ESTIMATED` | 微安级负载 + 脉冲降额 ~10% |
| nRF52840 睡眠（System ON idle + RTC） | **2 µA** | `DATASHEET` | 厂商典型值 |
| BLE 平均电流 @1000 ms 间隔 | **10 µA** | `ESTIMATED` | 每事件 1 包 |
| BLE 平均电流 @500 ms | **18 µA** | `ESTIMATED` | |
| BLE 平均电流 @100 ms | **80 µA** | `ESTIMATED` | |
| BLE 平均电流 @15 ms | **550 µA** | `ESTIMATED` | 只给充电电池 |
| FSR 分压（100 kΩ 上拉，占空 10%） | **3 µA** | `ESTIMATED` | 用 GPIO 门控供电 |
| 霍尔（DRV5032） | **3 µA** | `DATASHEET` | µA 级 |
| 其他漏电（电容/PCB） | **2 µA** | `ESTIMATED` | |

## 2. 模型

```
总平均电流 I = 睡眠 + BLE(间隔) + 传感器门控 + 漏电
续航 h = 可用容量 / I
```

| 连接间隔 | I 合计 | 续航 | 换电频率 |
|---|---|---|---|
| **1000 ms** | ≈19 µA | **≈10,500 h ≈ 438 天** | 一年多 |
| **500 ms** | ≈27 µA | **≈7,400 h ≈ 308 天** | 约 10 个月 |
| **100 ms** | ≈89 µA | **≈2,250 h ≈ 94 天** | 约 3 个月 |
| 15 ms | ≈559 µA | ≈358 h ≈ 15 天 | 必须充电电池 |

**结论 1：免充电（纽扣）在 500 ms–1 s 间隔下，理论续航 10 个月到 1 年——体验上成立。**

## 3. 脉冲电流与电压跌落（比平均电流更容易翻车的地方）

| 项 | 取值 | 结论 |
|---|---|---|
| CR2032 内阻 | 10–20 Ω | `ESTIMATED` |
| nRF52 TX 峰值（0 dBm） | 5–7 mA | `DATASHEET` |
| 峰值电压跌落 | 20 Ω × 7 mA ≈ **140 mV** | 3.0 V → 2.86 V |
| nRF52 欠压阈值 | 1.7 V | 余量充足 |

**但要注意**：纽扣电池的**长期大脉冲**会加速内阻上升。缓解措施：
1. 并联 **10–47 µF** 靠近模块供电脚；
2. 限制 TX 功率（0 dBm 或更低，室内已足够）；
3. 拉长连接间隔（脉冲频率更低）。

**结论 2：电压跌落不构成风险，但必须加去耦电容并限制发射功率。**

## 4. 这条模型不能替代什么

| 风险 | 为什么模型看不出 | 由谁验证 |
|---|---|---|
| 真实平均电流 | 厂商典型值与实际固件差异可达 2–3 倍 | **V7**（样品 + 电流表） |
| 唤醒延迟 | 模型不含时间 | **V6**（样品实测） |
| 低温/老化容量衰减 | 未建模 | 长期试玩 |
| 连接参数协商的真实开销 | 模型按稳态估 | V7 |

## 5. 判据

| 项 | 门槛 | 模型值 | 判定 |
|---|---|---|---|
| 500 ms 档续航 | ≥6 个月 | **≈10 个月** | ✅ 通过（模型） |
| 1000 ms 档续航 | ≥6 个月 | **≈14 个月** | ✅ 通过（模型） |
| 峰值电压跌落 | < 1.0 V | ≈0.14 V | ✅ 通过 |
| 15 ms 档用纽扣 | — | 15 天 | ❌ 不成立 → 扳机模块必须用充电电池（与既有设计一致） |

**结论：V5 模型通过；免充电方案的理论前提成立，最终以 V7 实测为准。**
