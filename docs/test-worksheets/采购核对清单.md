## 5. 到货后逐件核对动作（对应 01 表）

1. 六面拍照，命名放入同目录 `证据/`；表格里只写相对路径或文件名。
2. 每件测：裸件长×宽×高 → **带接头/弯线后包络** → 质量（0.1 g 秤）。
3. 每件电气：空载/上电电压、**极性确认**；电池同时查 PCM 保护与 NTC。
4. 数据出处分三档：`DATASHEET`（厂商手册）/ `ESTIMATED`（纸面推算）/ `MEASURED`（实测+证据）。与计划冲突不覆盖旧值，走 ADR。

## 6. 新手避坑速记（对应 00-从这里开始.md 停止条件）

- 台式电源第一次上电：**先设限流**（如 0.5 A）→ 空载测电压 → 再升流；任何异常立即断电。
- XIAO 电池接法：**先测极性**；电池必须带 PCM；USB-C 充电时节点停用、硬开关置于允许电池连接的位置。
- 成品充电宝：认准固定5V口；持续/峰值能力按Zero 3W台架数据选，旧≥3A不再自动算通过；**不用PD诱骗板**；屏幕不得反向给主板供电。
- MicroSD：到手先备份镜像；**破坏性断电测试只在备份卡上做**。
- FSR/握套：可拆、不粘原枪、不钻孔；任何改变扳机/握持安全的方案直接否决。
- 上枪前必须先后通过桌面闭环和断电机械假体；P0 不接火控、电机、供弹等执行线路。
