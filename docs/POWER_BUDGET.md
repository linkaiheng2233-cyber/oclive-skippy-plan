# 无线功能节点电池与功耗预算

## 1. 边界与当前决定

本文只冻结 Grip/Shoulder 等 BLE 功能节点的电源路线。Linux 导轨主机的电池取决于最终开发板、屏幕亮度和 Wi-Fi 实测，单独立项，不与毫瓦级传感器节点共用续航假设。

下场 Alpha 的 Grip Node 默认使用**用户可更换 CR2032 一次电池**：

- 不依赖磁性底座、磁吸触点或充电仓。
- 不在每个节点上增加 USB-C、充电管理和软包锂电。
- 电池耗尽后可在场地更换，所有功能节点尽量统一一种规格。
- CR1632 只保留为体积确实压不下去时的紧凑备选。
- CR2032/CR1632 都是一次电池，固件、外壳和说明不得暗示可充电。

## 2. 为什么先选 CR2032

| 方案 | 官方标称尺寸/容量 | 优点 | 代价 | 当前结论 |
|------|-------------------|------|------|----------|
| CR2032 | 20.0 × 3.2 mm，220 mAh | 常见、可更换、容量较高；官方有 10 mA/100 ms 脉冲闭路电压数据 | 外壳宽度至少约 24–26 mm；射频脉冲仍需实测 | 下场默认 |
| CR1632 | 16.0 × 3.2 mm，140 mAh | 直径小 4 mm，适合紧凑节点 | 标称容量比 CR2032 少约 36%；余量更小 | 紧凑备选 |
| 100–200 mAh 软包锂电 | 取决于具体电芯 | 可充电，形状选择多 | 需要保护/充电/接口；不得处于握把受压、穿刺或撞击路径 | v0.1 不用 |
| AAA | 约 10 mm 直径、长度较大 | 易买易换、容量高 | 节点过长、破坏贴片化形态 | 不进入 Grip Node |

选择 CR2032 不是因为它能直接承受任意 BLE 波形。Murata 标准数据给出的 CR2032 标准放电电流是 0.2 mA，而 nRF52832 官方规格的 0 dBm TX/RX 峰值约为 5.3/5.4 mA。CR2032 数据表提供了 10 mA、100 ms 的脉冲闭路电压参考，但完整节点仍必须验证电池内阻、电量末期和低温时的压降。

PCB 需要在电池附近预留低漏电储能电容和测量点，具体容量不在纸面冻结；使用示波器/功耗仪采集实际广播、连接、通知和重连脉冲后决定。不得用“220 mAh ÷ 平均电流”替代脉冲压降与温度测试。

## 3. 节点电源状态

```text
Storage
  │  装入电池 / 上电
  ▼
Dormant ──压力越阈值──→ Reconnect Burst ─→ Session Connected
  ▲                                            │
  └────主机长期不可见 / 握持释放 + 超时────────┘
                         │
                         └→ Low / Critical Battery
```

- `Storage`：长期存放时拆下电池或使用绝缘拉片；首版不为极小节点强行增加容易误触的电源开关。
- `Dormant`：MCU 深睡，由压力前端/LPCOMP 或周期性低功耗检查唤醒；不维持高频广播。
- `Reconnect Burst`：握持成立后向已绑定主机进行短时快速重连，成功后发送当前状态快照。
- `Session Connected`：下场会话期间使用较长连接间隔、slave latency 和状态变化通知；不上传连续压力曲线。
- `Low/Critical`：降低非必要状态上报频率，但不得吞掉握持释放事件。主机与屏幕提示更换电池。

Grip Node 没有 IMU：它靠压力唤醒。导轨主机的 IMU 负责载体移动/静止；Linux 主机在首版只关闭/降低屏幕并进入应用级待机，不假定开发板一定支持可靠 suspend-to-RAM。后续只有实机证明 IMU GPIO 可以稳定唤醒所选板卡，才启用系统级休眠。

## 4. 续航测试门

不在选定 BLE 模块、压力前端、连接参数和电池夹之前承诺“可用几个月”。统一记录以下实测值：

| 指标 | Alpha 记录要求 |
|------|----------------|
| Dormant 平均电流 | 23℃、新电池和半电量电池 |
| Session Connected 平均电流 | 主机近距离与人体/载体遮挡两种工况 |
| TX/RX/重连峰值与最低电压 | 新电池、半电量、接近低电阈值；23℃和低温 |
| 握持到主机确认延迟 | p50/p95，包含 Dormant 唤醒与重连 |
| 一次 4–8 小时场地下场耗电 | 前后静置电压、负载电压和估算电量 |
| 低电告警 | 不误报、不在一次射频脉冲后抖动恢复 |

阶段目标：

- 下场一次 8 小时不重启、不掉电。
- 电量末期和低温下 BLE 峰值不触发 brownout。
- 以“每周一次 8 小时会话、其余时间 Dormant”的回放工况，Alpha 最低目标为 90 天，设计目标为 180 天；这是验收目标，不是当前续航承诺。
- 连续 20 次休眠唤醒/断连重连后，状态快照与 sequence 仍正确。

## 5. 电量上报

`node.status` 必须包含：

- `power_source`: `bench | cr2032 | cr1632 | other`
- `battery_mv`: 可测量时上报负载/静置策略定义下的毫伏值。
- `battery_state`: `normal | low | critical | unknown | not_applicable`
- 固件与校准版本。

纽扣电池的电压、温度、内阻和脉冲负载相互影响，UI 不在 Alpha 阶段显示虚假的线性百分比，只显示“正常 / 低 / 立即更换”。阈值在整节点放电与脉冲测试后冻结，并使用迟滞防止来回跳变。

## 6. 机械与场地要求

- 电池盒位于压力感应区之外，不能把电芯作为力集中器或结构承力件。
- 使用带防松结构的螺钉盖/滑盖和可更换密封圈；摔落后电池不得瞬断或弹出。
- 预防反装和金属异物短路；备用纽扣电池单独绝缘携带。
- 天线 keep-out 不得被电池、金属导轨或手掌完全遮挡。
- 电池门、固定件和节点都不能妨碍握持、操作件或快速拆卸。
- 不使用磁性放置底座、磁吸充电或依靠外部磁体判定待机。

## 7. 原型决策顺序

1. 桌面电源完成压力采样、LPCOMP 唤醒和 SensorObservation。
2. 用 CR2032 电池夹完成脉冲、重连、低温和 8 小时回放。
3. 同一固件换 CR1632，只比较实际体积、压降和续航，不凭标称容量决定。
4. CR2032 能满足节点尺寸时直接保留；只有直径成为明确机械阻碍才改 CR1632。
5. 冻结电池后再设计密封外壳和定制 PCB。
