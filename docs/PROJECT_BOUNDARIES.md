# A.I.Live-ai枪娘器灵项目边界

**状态**：ACCEPTED  
**最后核对**：2026-09-04  
**目的**：防止四季宝硬件宿主、OCLive通用内核、角色内容和未来想法重新混在一起。

## 1. 本仓负责

- 枪械感知内核：节点身份、时效、校准、多传感融合、Unknown语义、PerceptionState和DeviceEvent。
- 实体Host：BLE/Linux/显示/触摸/电源生命周期适配，Input Scheduler和Output Arbiter。
- 前下导轨与后握把节点的固件契约、测试夹具和故障降级。
- 三轴一体主机舱、通用导轨底座、电源域、线缆、散热和机械验证。
- 四季宝专用枪械交互伴随包格式、安装/绑定和与基础角色的窄关联。
- 本项目的板端资源Profile、实机证据、测试表、ADR和交付镜像。

## 2. OCLive兄弟仓负责

- 通用角色身份、人格、记忆、关系、情绪、场景和角色回合。
- 标准角色包与蓝图格式、模型provider和通用资源协调能力。
- 跨宿主通用的`TurnOrigin`及其副作用语义。

本仓不能复制一份OCLive内核或修改其标准角色包来容纳枪械专用字段。确有通用改动时，先读取兄弟仓治理文件，在兄弟仓实现并测试，再由本仓窄适配。

## 3. 内容资产负责

- AN94等角色文本、图像、声音、Live2D模型和授权属于OCLive角色资产/内容发行，不属于感知内核。
- 本仓可保存无头测试夹具、事件到表现语义的伴随配置和审核语音索引，但不把正式角色资产许可证混同于MIT代码许可证。
- 用户为枪械互动开发的伴随包是二次开发格式，不是OCLive标准角色包的新标准。

## 4. 阶段边界

| 类别 | P0当前范围 | P1/P1+候选 | 项目外/禁止 |
|---|---|---|---|
| 感知 | 握持、运动、重力姿态、只读辅助触点 | 更多节点、只读机械循环、只读余弹粗范围 | 目标识别、自动瞄准、弹道计算 |
| 输出 | 800×480 PNG/HUD/System UI | TTS/ASR、审核语音池、Live2D | 让模型控制执行机构 |
| 视觉 | 无相机 | 拐角视野、录像、只读HUD实验 | 自动跟踪目标、射击解算 |
| 载体接口 | 外挂导轨、后握薄套、无机内跨节点线 | 独立只读传感适配，经新ADR/契约 | 控制火控、电机、扳机、供弹 |
| 模型 | 可选3B及以下角色短句测试 | 按任务分流、RAG、LoRA/审慎全量微调 | 让LLM成为安全/UI/关机前提 |
| 产品 | 娱乐、把玩、wargame角色陪伴 | 经过验证的消费级原型 | 军警、实战或伤害增强用途 |

“水弹智能瞄准”个人思维实验在其原文件中已经声明独立于本仓，并且跨越本项目禁止边界，因此不导入、不引用为backlog，也不能通过改名为“视觉增强”绕过。

## 5. 物理边界

- 首个验证载体是森柏龙RADIAN MODEL 1，但电子核心和软件契约不绑定单一外壳。
- P0默认不进入机匣/波箱走线，不拆改火控；前后节点各自供电，通过BLE通信。
- 主机、前节点、后节点是三个独立电源域。任何共地或供电连接必须在局部电路图中显式出现。
- 屏幕移动舱不承担枪体结构载荷；LCD、电池和PCB不作为夹具、止挡或碰撞受力件。

## 6. 信息边界

- FSR只提供接触/压力证据，IMU只提供运动/重力姿态证据，辅助触点只证明触点状态；它们不证明击发、命中、伤势、队友、目标或危险距离。
- 感知内核只产中性事实；Host决定是否形成角色回合；OCLive负责解释与表达。
- 系统错误、路径、堆栈、电池保护和协议封禁原因只进入维护UI，不交给角色扮演。
- 未测事实保持`UNKNOWN`；模型、文案和体验意见不能把它升级为物理事实。

## 7. 边界变更门

任何新增功能只要满足以下一项，就必须先写ADR再实现：

1. 新组件需要同时认识感知内核与OCLive内部对象。
2. 新线路进入发射器内部或连接原火控/电机/供弹。
3. 新模型可以改变安全关机、System UI或执行机构。
4. 新角色包字段试图进入OCLive标准格式。
5. 新视觉能力涉及目标检测、跟踪、瞄准或弹道。
6. 新硬件改变三个电源域或让线缆跨越三轴运动关节。

ADR必须写出用户价值、替代方案、故障开放方式、回退、机械/电气风险和需要新增的测试证据。没有通过边界评审的功能只能留在外部构思，不进入ROADMAP。
